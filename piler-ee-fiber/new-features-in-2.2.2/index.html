    What's new since 2.1.0#

    This documentation covers everything new in Piler enterprise edition from 2.1.0 through 2.2.2. For the detailed, release-by-release engineering changelog (including maintenance releases and dependency updates), see the Changelog.

    Revision #1

    Publication date: 2026-SEP-27

    Unified archiving for Slack and Microsoft Teams#

    Archive Slack and Microsoft Teams conversations alongside email in the same searchable, compliant archive - with dedicated collectors for each platform and matching UI/API support.

    GDPR Right to Erasure#

    A multi-node-aware implementation of the GDPR's Article 17 right to erasure, so erasure requests are honored consistently across every node in a multi-node deployment.

    Passkey authentication#

    Sign in with passkeys (WebAuthn) instead of, or alongside, passwords - phishing-resistant authentication with no shared secret to steal.

    Find similar messages#

    A new KNN vector search over message content surfaces similar messages directly from the message view, complementing full-text and semantic search.

    Multi-master-node high availability#

    The archive can now run with multiple master nodes instead of a single master, removing that node as a single point of failure in multi-node deployments.

    Resumable IMAP import#

    Large IMAP import jobs now checkpoint their progress, so an interrupted import picks up where it left off instead of starting over.

    Pending conversations#

    A dedicated badge and drawer surface messages that are awaiting a reply, so nothing important gets missed in a busy mailbox.

    SIEM integration#

    Ship archive events to your SIEM, including native Sumo Logic support.

    NIS2 compliance documentation#

    Documentation covering how Piler's archiving and access controls map to the EU's NIS2 directive requirements.

    Open-Xchange (OX) webmail integration#

    Tighter integration with OX webmail: matching theme, language, and timezone, plus iframe embedding support.

    MSP customization hooks#

    Stable HTML hooks and CSS identifiers throughout the UI, so managed service providers can apply their own branding and customizations without patching Piler itself.

    Attachment search#

    Search archived attachments directly, not just message bodies and subjects.

    Flexible S3-compatible storage#

    New tuning options for S3-compatible backends - skip re-uploading objects that already exist across nodes, and control multipart upload part size, for better performance on constrained or high-latency storage backends.

    Expanded purge controls#

    Restore from a specific prior purge run, and purge is now multi-node aware, so retention policies apply consistently across every node in a deployment.
