    Supported versions#

    This documentation applies to Piler enterprise edition releases 2.3.3+

    Revision #1

    Publication date: 2026-NOV-13

    Piler enterprise has two release lines:

    Line Versions Contains Supported until
    2.3 LTS 2.3.3, 2.3.4, … bug fixes, security fixes, dependency and toolchain updates 2028-05-31
    Mainline 2.4.0, 2.5.0, … new features, fixes the latest release, until the next one

    Older versions (2.3.2 and earlier, 2.2.x and earlier) get no fixes: upgrade to the latest 2.3.x or to the latest mainline release.

    The LTS line#

    An LTS (long-term support) line gets no new features: its patch releases (2.3.4, 2.3.5, …) only fix bugs and security issues, and update the dependencies and the Go toolchain when they need security fixes. An LTS upgrade adds no new settings, no new UI and no database migrations, so it can be installed without changing the configuration.

    A new LTS line is expected about every 12 months. Each one is supported for 18 months, so two LTS lines overlap for about 6 months to give time for the upgrade.

    The Scanner add-on follows the same rule: 1.3.x is the version for the 2.3 LTS.

    Docker images#

    Every release has its own image tag (sutoj/piler-ee:2.3.3). The images of the LTS line also have a tag that moves to its latest patch release:

    Image LTS tag
    sutoj/piler-ee, sutoj/piler-ui, sutoj/s3uploader, sutoj/retriever, sutoj/slack, sutoj/teams 2.3
    sutoj/scanner 1.3

    A pinned version tag (2.3.3) changes only when you change it; the 2.3 tag gets the fixes with a docker compose pull. Either way, read the changelog before an upgrade.

    The mainline#

    New features are released in the mainline only, in a new minor version (2.4.0, 2.5.0). The fixes are made in the mainline first and backported to the LTS. Only the latest mainline release gets fixes: a fix for 2.4.0 comes in 2.4.1 or a later version.

    Upgrading from the LTS to the mainline#

    Any 2.3.x can be upgraded to any later mainline release, following Upgrading piler enterprise and the upgrade steps of each version in the changelog.
