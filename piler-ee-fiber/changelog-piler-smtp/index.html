    piler-smtp changelog#

    All notable changes to piler-smtp, the SMTP receiver of Piler Enterprise Edition, starting from 1.1.2. piler-smtp is versioned and released independently of the main application, see the Piler Enterprise changelog.

    Packages (deb, rpm) and Docker images (sutoj/piler-smtp) are on the releases page.

    1.1.6 - 2026-10-17#

    Fixed#

    • An archive address encoded again by the mail server is no longer recorded as an envelope recipient. This happens when the mail server's archiving rules also run for the archive copies they added (seen with Axigen Acceptance & Routing rules). The address is logged, and the email is still archived with its other recipients.

    1.1.5 - 2026-10-13#

    Fixed#

    • The ownership of /var/piler set by the deb package's post-install script.

    1.1.4 - 2026-10-07#

    Added#

    • Envelope files (enable_envelope_sidecar, off by default): the envelope of each email is written to a .env file next to it, with the envelope sender and the envelope recipients encoded in the archive address (<tenant>+<local part>=<domain>@<archive host>), so that Bcc recipients can be archived. See Envelope recipients. Needs Piler Enterprise 2.2.4 or later.

    Security#

    • Hardened the SMTP input handling: limits on lines without a line ending, correct handling of BDAT chunks (with enable_chunking=1), bare LF line endings and NUL bytes in the message.

    1.1.3 - 2026-09-01#

    Added#

    • Packages for Ubuntu 26.04.

    Fixed#

    • A deadline for every connection that sending a byte now and then can't extend, and a limit on the connections from one IP address, so one client can no longer keep others from connecting.
    • With smtp_access_list=1, an empty or unreadable access list now rejects every client instead of allowing all of them.
    • Package dependencies.

    1.1.2 - 2026-01-12#

    Fixed#

    • Session handling.
    • arm64 deb package build.
