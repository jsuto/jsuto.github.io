    What's new in 2.2.4#

    This documentation covers everything new in Piler enterprise edition 2.2.4 (2.2.3 was not released). For the detailed engineering changelog, including fixes and security improvements, see the Changelog.

    Revision #1

    Publication date: 2026-OCT-17

    Piler in Outlook#

    The new Outlook add-in brings the archive into Outlook: users search the archive, preview a message, read it in full and restore it to their mailbox without leaving their mail client. It works in Outlook on the web, the new Outlook for Windows, classic Outlook and Outlook for Mac, with the same login and the same permissions as the web UI.

    piler-ui serves the add-in itself, so there is nothing else to install on the archive: enable it, and deploy the manifest to your users from the Microsoft 365 admin center. The add-in asks Outlook for the lowest permission, and reads nothing of the mailbox. See Outlook add-in.

    Bcc recipients find their mail#

    A Bcc recipient is in no header of an email, so an archive that reads the headers alone doesn't know about them. Piler now archives the recipients of the SMTP envelope too, so a Bcc recipient finds the email in their own search, just like the To and Cc recipients. An email delivered in several SMTP transactions ends up as one archived email with all its recipients. See Envelope recipients.

    Bcc recipients for migrated mail#

    When you migrate an archive with pilerimport, give the recipients of each email in a small file next to it, and the Bcc recipients are archived as well. For mail you have migrated already, pilerimport can add the missing recipients without importing anything again, with a dry run to check first and an audit log entry for every change. See Migrated mail.

    The envelope sender for auditors#

    Auditors see the envelope sender of each email, with a warning when it differs from the From header, and can search by it.

    Message variants#

    When one message is delivered to each recipient with a different body, e.g. with links rewritten per recipient, Piler can archive each version as a message of its own (ARCHIVE_MESSAGE_VARIANTS), so every recipient finds the copy they got. Auditors see the other versions as related copies.

    Recipients from a journaling header#

    EXTRA_RECIPIENTS_HEADER archives the addresses of a header your mail server or journaling setup adds, e.g. X-Envelope-To, as recipients.
