    Scanner changelog#

    All notable changes to the Scanner add-on (ML phishing detection, semantic search, PII detection, categorization), starting from 1.2.0. The Scanner is versioned and released independently of the main application, see the Piler Enterprise changelog.

    1.3.1 - 2026-10-23#

    Fixed#

    • The scanner ignored PILER_STORE_DIR and PILER_ASTORE_DIR when it read the emails from the store directly: it always used /var/piler/store/<server id>, and looked for the attachments in the wrong directory. It uses the configured directories now.
    • PILER_STORE_DIR without a trailing slash (e.g. /srv/piler/store) gave a wrong store path, and no email could be read.
    • SEMANTIC_SEARCH_MAX_TOKENS limited the email body in bytes, not characters, so a Hebrew or Cyrillic email got about half the text of an English one, and the cut could split a character. Emails embedded earlier keep their embeddings until they are embedded again, e.g. by running the scanner with -backfill.

    Changed#

    • The scanner logs a warning when it reads the emails through retrieverd (RETRIEVER_METHOD=socket), which is not recommended and will be phased out.

    1.3.0 - 2026-09-27#

    Changed#

    • The ML phishing detector no longer depends on a native runtime library or CGO - it's now a fully static, dependency-free Go binary. This makes the scanner image smaller, faster to build, and easier to deploy across architectures.
    • Retrained the phishing-detection model on a substantially larger and more diverse set of examples. Internal testing shows a meaningful reduction in false positives (legitimate email incorrectly flagged) versus the previous model, with no loss in detection rate.
    • Simplified the scanner's Docker image build to a prebuilt-binary copy, matching the main application image's build process.

    1.2.0 - 2026-08-16#

    Changed#

    • Semantic search embeddings are computed by an external, OpenAI-compatible endpoint (SEMANTIC_SEARCH_ENDPOINT_URL, e.g. Ollama) instead of in-process ONNX models. The model is your choice; see Semantic search.
